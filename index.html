RULE 01
最優先ルール：大きく負けない
自分が把握していない銘柄は、買うポイントも売るポイントも分からない。値動きだけで入ると過去に大きく負けている。
  • 事業内容・業績・テーマ性・材料を把握していない銘柄は買わない
  • 「下がりすぎだからリバウンドしそう」という理由だけで買わない
  • 「急に上がり始めたから乗りたい」という理由だけで買わない
  • セクター全体の急落後のリバウンド狙いを、即興で行わない
  • 買う理由・売る理由・損切りラインが説明できない銘柄は買わない
RULE 02
決算またぎは基本的にしない
決算またぎは、上がる理由よりも下がる理由の方が多く、再現性が低い。期待してまたいだ結果、利益を飛ばした経験がある。
  • 思惑だけの決算またぎは禁止
  • 好決算でも、材料出尽くし・コンセンサス未達で下がることを前提に考える
  • 決算前に含み益がある場合は、一部利確または全利確を検討する
  • 決算は「結果」だけでなく「市場の反応」を見てから入ることを優先する
RULE 03
大きな賭けに出ない
自信がある時ほど、過去の大負けを思い出す。小さい勝ちを積み重ねる方が自分には合っている。
  • 1銘柄に一気に300万〜400万円を入れない
  • 1回のエントリーは原則100万円以下に抑える
  • できれば30万円前後から打診買いする
  • シナリオに自信がある銘柄でも、段階的に100万円程度までにする
RULE 04
追いかけ買いをしない
低いところで入れたのに、急騰後に追従買いして平均単価を上げ、その後の押しで含み損化することが多い。
  • 安く買えた後に、すぐ追従買いしない
  • 窓を開けて上がった銘柄を追いかけて買わない
  • 追いかけ買いするくらいなら、利確を検討する
  • 5%以上急騰した日は、基本的に買い増ししない
RULE 05
仕込みは平常心の時に行う
大きく勝とうとしすぎず、小さい勝ちを積み重ねる。
  • 場中に焦って買わない
  • 板や1分足を見て興奮している時は買わない
  • 静かな時、横ばいの時、押し目の時に仕込む
  • 5〜10%上がった時は、買うよりも放置または利確を考える
  • 10万円程度の利益が出たら、一部利確も検討する
RULE 06
打診買いから入る
買った後に考えるのではなく、買う前に撤退条件を決める。
  • 最初から本気買いしない
  • まずは100株、または30万円前後で入る
  • 値動き・出来高・地合い・材料反応を見てから追加する
  • 想定と違えばすぐ切る
  • 打診買いの時点で損切りラインを決める
RULE 07
買う前に必ず確認すること
ファンダメンタルとチャートの両面から確認する。
  • 株探で業績を確認する
  • 売上・営業利益・EPSが伸びているか確認する
  • PER・PBRが業界内で高すぎないか確認する
  • 短期線・中期線・長期線の並びを確認する
  • 上昇トレンドか確認する
  • 損切りラインをどこに置けるか確認する
  • 出来高が急増しすぎていないか確認する
RULE 08
人から聞いた銘柄をすぐ買わない
人から聞いた銘柄は、入口は魅力的でも、出口を自分で決められないことが多い。
  • 先輩・友人・詳しい人から聞いた銘柄をすぐ買わない
  • まずはウォッチリストに入れる
  • 自分で調べる
  • 自分の買いポイントまで待つ
  • 自分のルールに合わなければ買わない
RULE 09
底当てゲームをしない
底を当てるのではなく、反転の兆しを確認してから入る。
  • 落ちているナイフは触らない
  • 下落中に「そろそろ底だろう」で買わない
  • 下げ止まりを確認してから入る
  • 下ひげ陽線・横ばい期間・出来高の変化を確認する
RULE 10
買うタイミングの基本ルール
「上昇トレンドの押し目買い」を基本とする。どこで買って、どこで切るか分かる形だけ入る。
  • 短期線・中期線・長期線が上向きである
  • 上昇トレンドの中の押し目である
  • どのラインで反発を狙うのか明確である
  • そのラインを割ったら損切りできる
  • 地合いが極端に悪い時は無理に入らない
RULE 11
勝ちパターン：テーマ株の静かな仕込み
急騰中に飛び乗るのではなく、静かな時に仕込む。
  • 旬のテーマに乗っている
  • 過去に何度か急騰している
  • 急騰後に落ち着いて横ばいになっている
  • 直近に大きな決算リスクがない
  • ダウンサイドが限定的に見える
  • 100万円程度までなら仕込む価値がある
RULE 12
ナンピンは原則しない
過去にナンピンで大きく痛い思いをしているため、基本は禁止。
  • 想定と違う下落でナンピンしない
  • 含み損を助けるためのナンピンはしない
  • 長期線を割ったらナンピンではなく撤退を優先する
RULE 13
感情が動いている時は買わない
負けの多くは「値動きに反応してしまった時」「取り返したい時」に起きやすい。
  • 悔しい時に買わない
  • 取り返したい時に買わない
  • 急騰を見て焦って買わない
  • 損切り直後に別銘柄へ飛びつかない
  • 「今日中に取り返したい」と思ったら、その日は新規買いしない
  • 大きく勝った直後も、気が大きくなっているので買わない
RULE 14
寄り付き・PTSを信用しすぎない
PTSと本市場の動きは別物。特に決算後は、寄り付き前の期待と実際の需給が大きくズレることがある。
  • PTSで上がっていても、翌日の寄り付きで同じように上がるとは考えない
  • 特買い・特売り・ギャップアップ直後に飛びつかない
  • 最低でも5〜10分、できれば前場の流れを見て判断する
  • 寄り付きで高く始まった銘柄は、押しを待つ
RULE 15
1日の中で無理に勝負しない
「何もしない」ことも立派な投資判断。
  • その日に買う理由がなければ買わない
  • チャンスがなければノートレードでよい
  • 金曜日・決算集中日・重要イベント前は無理しない
  • 相場全体が荒れている日は、ポジションを増やさない
RULE 16
ポジション管理ルール
リスクの分散と、含み益のある時の一部利確を意識する。
  • 1銘柄に集中しすぎない
  • 1銘柄300万円超えは原則避ける
  • テーマ株・小型株は100万円程度までを目安にする
  • 高ボラ銘柄は30万円〜50万円程度から入る
  • 含み益が出たら、一部利確してリスクを下げる
  • 含み損が出たら、買い増しではなくシナリオ確認を優先する
RULE 17
損切りルール
損切りは負けではなく、次のチャンスに資金を残すための行動。
  • 買う前に損切りラインを決める
  • 決めたラインを明確に割ったら撤退する
  • 想定と違う動きなら、含み損が小さいうちに切る
  • 損切り後にすぐ買い直さない
RULE 18
利確ルール
「もっと取れた」は気にしない。「大きく負けなかった」を重視する。
  • 短期で10万円程度の利益が出たら、一部利確を検討する
  • 急騰して窓を開けたら、一部利確を検討する
  • 決算前に含み益がある場合は利確を優先する
  • 目標株価に近づいたら、欲張りすぎない
  • 利確後にさらに上がっても後悔しない
RULE 19
自分に合う投資スタイル
業績・テーマ・チャートを確認して、押し目で小さく入り、強ければ伸ばす。
  • 副業として続けられるスタイルにする
  • 1分足や板に張り付かない
  • 日足・週足ベースで判断する
  • 夜眠れないポジションは持たない
  • ドキドキする投資はしない
  • 勝率と再現性を重視する
RULE 20
値動きを見すぎない・時間管理を徹底する
自分はデイトレーダーではなく、スイングまたは中長期の投資家。本業の時間や集中力を削るのは本末転倒。
  • 毎分・毎秒の値動きチェックはしない
  • 9:00〜10:00頃：寄り付き後の大まかな方向感を確認
  • 11:30頃：前場終了時点での動きを確認
  • 15:00〜15:30頃：大引け前後の動きと翌日に向けた判断
  • シナリオを持って買った銘柄は、短時間の値動きに振り回されない
